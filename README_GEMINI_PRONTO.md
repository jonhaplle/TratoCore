TRATOCORE - GEMINI
==================

Esta versao usa a Gemini API no fluxo principal de analise.
O Ollama/Gemma nao e necessario para o botao de analise.

Instalacao/atualizacao:
1. Execute ATUALIZAR_TRATOCORE_GEMINI.bat como Administrador.
2. Se ainda nao houver chave, execute C:\TratoCore\CONFIGURAR_GEMINI.bat.
3. O sistema abre http://localhost:3000.

Publicacao:
A publicacao do Mercado Livre continua usando a API oficial do Mercado Livre.

Browser Engine:
Continua disponivel separadamente para leitura de pagina, DOM e screenshot.
